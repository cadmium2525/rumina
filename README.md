# ルミナ

スーパーマリオワールド（[snesrev/smw](https://github.com/snesrev/smw) の逆アセンブル C ソース）の
プレイヤー処理を移植した、ルミナが主人公のアクションゲームです。

現在は「平坦な地面でルミナの操作感を確認する」段階です。

## 起動

ビルド不要です。静的ファイルとして配信してください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

スマホからは同じネットワーク内で `http://<PCのIP>:8000/` を開きます。
（Service Worker / PWA インストールには HTTPS か localhost が必要です）

## 操作

| 操作 | キーボード | タッチ / ゲームパッド |
| --- | --- | --- |
| 移動 | ← → / A D | 十字キー |
| ジャンプ（押し続けると高く跳ぶ） | X / K / Space | B |
| スピンジャンプ | C / L | A |
| ダッシュ | Z / J / Shift | Y（X） |
| しゃがむ / 上を見る | ↓ / ↑ | 十字キー |
| ポーズ | Enter | START |
| ギフトを持つ（押している間） | Z / J / Shift | Y（X） |

- タッチでは、最初に押したボタンは指を離すまで押されたままです。Y を押したまま親指を B へスライドすると Y+B（持ったままジャンプ・ダッシュジャンプ）になります。Y と B の間を押しても両方入ります。
- R キー（画面右上の ↺）でリセット、F2（または i）でデバッグ表示。
- 画面右上の「振」で、ボタンを押したときの振動を切り替えられます（Android は振動、iOS Safari は触感フィードバックを利用。端末によっては効きません）。

## ブロック・アイテム・敵

SMW のスプライト処理（bank 01/02）を移植しています（`js/actors.js`）。

- **ギフトボックス**（SMW のスローブロック）：Y を押しながら触れると持ち上げ、Y を離すと前へ投げます（SMW の甲羅と同じ規則）。
  ↑ を押しながら離すと真上へ、↓ を押しながら離すとそっと置きます。持ったまま ↓ でしゃがむと足元で抱えます。
  押さずに触れると蹴り飛ばし、壁に当たると砕けます。持っている間はスピンジャンプできません。
- **甲羅**（SMW のノコノコの甲羅）：ギフトと同じく持つ・投げる・置くができます。蹴る/投げると滑り、壁に当たると跳ね返ります（ブロックを叩く）。
  滑っている甲羅は敵を倒し、横から当たるとダメージ。上から踏むと止まり（ルミナは跳ねる）、スピンジャンプで踏むと消えます。
- **金のブロック**（ターンブロック）：空中でスピンジャンプ中に着地すると壊れ、ルミナが少し跳ね返ります（縦速度 -48。ジャンプボタンを押していると重力が弱いので約 2 倍高く跳ぶ）。段を重ねたブロックは跳ねながら順に壊せます。
  下から叩く（または滑る甲羅・ギフトが横から当たる）と、SMW のクルクルブロックのように跳ねてから回り始め、回っている間はすり抜けられます。叩いてから 256 フレーム（約 4.3 秒）で元に戻ります。
- **トゲムシ**：普通に踏む・横から触れるとダメージ（SMW と同じくノックバックは無く、一定時間無敵になって点滅）。
  スピンジャンプで上から踏むと倒さずに跳ね返ります（B を押していると高く跳びます）。投げたギフトで倒せます。
- **坂**（SMW の坂の形 `SlopeDataTables`）：ゆるい坂（2 タイルで 1 段）と 45° の坂。坂ごとの加速・最高速・摩擦の表を使い、
  45° の坂で何も押さないとゆっくり滑り落ちる（静止速度 -16）。速く登ると坂に沿った上向きの速度になる。
  坂で ↓ を押すとしゃがみ滑り（ポーズ 0x1C）になり、坂を下る向きに加速する。滑っている間は敵を倒す。
  丘の頂上と中身は「上からだけ乗れる足場」（SMW の map16 0x100〜0x110 相当）で、坂の真下の地面は SMW の坂補助タイル（0x1D8〜）と同じく上の坂として扱う。
- **水中**（`HandlePlayerPhysics_Swimming`）：体の中心と頭が水に入ると泳ぐ。B で水をかく（-32）、重力は 4 フレームに +2、
  上昇の上限は -24（↑ で -48、↓ で -8）、沈む速さは最大 0x40。水面では ↑+B で飛び出す（-86）。物を持っているとゆっくり浮かぶ。
- **ツタ**（`HandlePlayerPhysics_Climbing`）：体の中心と頭がツタにかかった状態で ↑/↓ を押すとつかまる。上下は 1px/フレーム、
  頭がツタから出ると止まる。横は中心がツタにある間だけ動け、外れると手を離す。B で飛び降りる（-80）。
- **天井の坂**（SMW の坂の形 18〜23 番：45° と、2 タイルで 1 段のゆるい坂）：頭の点が坂の固い部分に入ると押し戻され上昇が止まる（`RunPlayerBlockCode` の LABEL_62）。
  地上で頭が 7px 以内だけ入るなら頭打ちのみ、深いと前へ進めない。坂の真上のブロックは SMW の補助タイルと同じく下の坂として扱う。
- **チビルミナ**（パワーアップ $19）：SMW と同じく小さい状態で始まる。判定点・当たり判定はしゃがみと同じ、歩きは 2 コマ、物は +15 の高さで持つ、
  スピンジャンプでターンブロックを壊せない。**？ブロック**を叩くと光の玉（動きは SMW のキノコと同じ：62 フレームでブロックから出て 1px/フレームで転がる）。
  光の玉を取ると大きくなる（47 フレーム停止）。大きい時のダメージで縮み（47 フレーム停止の後 0x7F フレーム無敵）、小さい時のダメージ・穴に落ちるとミス
  （`PlayerState09_Death`：縦速度 -112、最初の 40 フレームは静止、4 フレームに 1 減るタイマー 0x30 が 0 でやり直し）。
- ブロックとの当たり判定は SMW の `RunPlayerBlockCode` と同じ 6 点（中心・左右の横 2 点・頭・足 2 点）方式です。
  立ちは 中心 y+0x12 / 横 y+0x1A・y+0x0F / 頭 y+0x08 / 足 y+0x20、しゃがみは 中心 y+0x18 / 横 y+0x1A・y+0x16 / 頭 y+0x10。

## SMW から移植した挙動

`js/player.js` は SMW の `PlayerState00`（$00CC68）以降を、8bit/16bit 演算の
桁あふれも含めて再現しています。テーブルは `js/smw_tables.js`。

- 加速・減速・切り返し（ブレーキ加速）・最高速（歩き 20 / ダッシュ 36 / P スピード 48）
- 最高速付近での速度の振動（加速 0x180 と減速 0x100 が交互にかかる）
- P メーター（ダッシュ 35 以上で +2/フレーム、満タン 0x70）
- 速度で変わるジャンプ初速、B 押しっぱなし時の重力 3 / 離し時 6、落下速度上限
- スピンジャンプ、しゃがみ（しゃがみジャンプ含む）、上を見る
- 歩き/走りアニメーションの速度テーブル、ポーズ選択
- カメラの横スクロール（$00F6DB、進行方向へ 1px 先行）と画面端の押し戻し
- 60.0988 Hz 固定フレーム

### ルミナの挙動で SMW と違うところ（意図的なもの・未実装）

- パワーアップは光の玉（SMW のキノコ相当）だけ（マント・ファイア・スター・アイテムストックは無し）。残機・タイマー・ミス後のメッセージは無く、ミスすると即やり直し。
- 縮む・大きくなる途中の「中くらい」の絵 (0x3D) は、大きい立ちポーズを縦に縮めたもの。
- しゃがんで物を持っているとき、物の横位置を SMW より 4px 前に出している（ルミナの顔が隠れないための見た目の調整。高さは SMW と同じ +15）。
- ギフトボックスは「Y を離すと投げる、↓+離すで置く」（SMW の甲羅の規則）。SMW のスローブロックは左右を押していないと置く。
- 急な坂（45° より急な坂・壁走り）、水の坂、ネット（金網）、マント・ヨッシー・L/R スクロールは未実装。

## ドット絵

`tools/rumina_frames.txt` が原本（24x32、1 文字 = 1 ドット）です。
編集後は `python3 tools/build_frames.py` で `js/rumina_frames.js` を再生成し、
`python3 tools/preview_frames.py tools/rumina_frames.txt preview.png` で一覧を確認できます。
アイコンは `python3 tools/make_icons.py` で再生成します。
