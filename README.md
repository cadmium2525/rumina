# ルミナ

スーパーマリオワールド（[snesrev/smw](https://github.com/snesrev/smw) の逆アセンブル C ソース）の
プレイヤー処理を移植した、ルミナが主人公のアクションゲームです。

現在は「平坦な地面でルミナの操作感を確認する」段階です。

## 起動

ビルド不要です。静的ファイルとして配信してください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

スマホからは同じネットワーク内で `http://<PCのIP>:8000/` を開きます。
（Service Worker / PWA インストールには HTTPS か localhost が必要です）

## 操作

| 操作 | キーボード | タッチ / ゲームパッド |
| --- | --- | --- |
| 移動 | ← → / A D | 十字キー |
| ジャンプ（押し続けると高く跳ぶ） | X / K / Space | B |
| スピンジャンプ | C / L | A |
| ダッシュ | Z / J / Shift | Y（X） |
| しゃがむ / 上を見る | ↓ / ↑ | 十字キー |
| ポーズ | Enter | START |
| ギフトを持つ（押している間） | Z / J / Shift | Y（X） |

- タッチでは、最初に押したボタンは指を離すまで押されたままです。Y を押したまま親指を B へスライドすると Y+B（持ったままジャンプ・ダッシュジャンプ）になります。Y と B の間を押しても両方入ります。
- R キー（画面右上の ↺）でリセット、F2（または i）でデバッグ表示。
- 画面右上の「振」で、ボタンを押したときの振動を切り替えられます（Android は振動、iOS Safari は触感フィードバックを利用。端末によっては効きません）。

## ブロック・アイテム・敵

SMW のスプライト処理（bank 01/02）を移植しています（`js/actors.js`）。

- **ギフトボックス**（SMW のスローブロック）：Y を押しながら触れると持ち上げ、Y を離すと投げます。
  ← → を押しながら離すと前へ、↑ なら真上へ、何も押さなければそっと置きます。
  押さずに触れると蹴り飛ばし、壁に当たると砕けます。持っている間はスピンジャンプできません。
- **甲羅**（SMW のノコノコの甲羅）：ギフトと同じく持つ・投げる・置くができます。蹴る/投げると滑り、壁に当たると跳ね返ります（ブロックを叩く）。
  滑っている甲羅は敵を倒し、横から当たるとダメージ。上から踏むと止まり（ルミナは跳ねる）、スピンジャンプで踏むと消えます。
- **金のブロック**（ターンブロック）：空中でスピンジャンプ中に着地すると壊れ、ルミナが少し跳ね返ります（縦速度 -48。ジャンプボタンを押していると重力が弱いので約 2 倍高く跳ぶ）。段を重ねたブロックは跳ねながら順に壊せます。
  下から叩く（または滑る甲羅・ギフトが横から当たる）と、SMW のクルクルブロックのように跳ねてから回り始め、回っている間はすり抜けられます。叩いてから 256 フレーム（約 4.3 秒）で元に戻ります。
- **トゲムシ**：普通に踏む・横から触れるとダメージ（一定時間の無敵と小さなのけぞり）。
  スピンジャンプで上から踏むと倒さずに跳ね返ります（B を押していると高く跳びます）。投げたギフトで倒せます。
- ブロックとの当たり判定は SMW の `RunPlayerBlockCode` と同じ 6 点（頭・左右の横 2 点・足 2 点）方式です。

## SMW から移植した挙動

`js/player.js` は SMW の `PlayerState00`（$00CC68）以降を、8bit/16bit 演算の
桁あふれも含めて再現しています。テーブルは `js/smw_tables.js`。

- 加速・減速・切り返し（ブレーキ加速）・最高速（歩き 20 / ダッシュ 36 / P スピード 48）
- 最高速付近での速度の振動（加速 0x180 と減速 0x100 が交互にかかる）
- P メーター（ダッシュ 35 以上で +2/フレーム、満タン 0x70）
- 速度で変わるジャンプ初速、B 押しっぱなし時の重力 3 / 離し時 6、落下速度上限
- スピンジャンプ、しゃがみ（しゃがみジャンプ含む）、上を見る
- 歩き/走りアニメーションの速度テーブル、ポーズ選択
- カメラの横スクロール（$00F6DB、進行方向へ 1px 先行）と画面端の押し戻し
- 60.0988 Hz 固定フレーム

テスト: `node tests/physics.test.mjs && node tests/world.test.mjs`

## ドット絵

`tools/rumina_frames.txt` が原本（24x32、1 文字 = 1 ドット）です。
編集後は `python3 tools/build_frames.py` で `js/rumina_frames.js` を再生成し、
`python3 tools/preview_frames.py tools/rumina_frames.txt preview.png` で一覧を確認できます。
アイコンは `python3 tools/make_icons.py` で再生成します。
