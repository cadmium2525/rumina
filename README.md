# ルミナ

スーパーマリオワールド（[snesrev/smw](https://github.com/snesrev/smw) の逆アセンブル C ソース）の
プレイヤー処理を移植した、ルミナが主人公のアクションゲームです。

現在は「平坦な地面でルミナの操作感を確認する」段階です。

## 起動

ビルド不要です。静的ファイルとして配信してください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

スマホからは同じネットワーク内で `http://<PCのIP>:8000/` を開きます。
（Service Worker / PWA インストールには HTTPS か localhost が必要です）

## 操作

| 操作 | キーボード | タッチ / ゲームパッド |
| --- | --- | --- |
| 移動 | ← → / A D | 十字キー |
| ジャンプ（押し続けると高く跳ぶ） | X / K / Space | B |
| スピンジャンプ | C / L | A |
| ダッシュ | Z / J / Shift | Y（X） |
| しゃがむ / 上を見る | ↓ / ↑ | 十字キー |
| ポーズ | Enter | START |
| ギフトを持つ（押している間） | Z / J / Shift | Y（X） |

- タッチでは、最初に押したボタンは指を離すまで押されたままです。Y を押したまま親指を B へスライドすると Y+B（持ったままジャンプ・ダッシュジャンプ）になります。Y と B の間を押しても両方入ります。
- R キー（画面右上の ↺）でリセット、F2（または i）でデバッグ表示。
- 画面右上の「振」で、ボタンを押したときの振動を切り替えられます（Android は振動、iOS Safari は触感フィードバックを利用。端末によっては効きません）。

## ブロック・アイテム・敵

SMW のスプライト処理（bank 01/02）を移植しています（`js/actors.js`）。

- **ギフトボックス**（SMW のスローブロック）：Y を押しながら触れると持ち上げ、Y を離すと前へ投げます（SMW の甲羅と同じ規則）。
  ↑ を押しながら離すと真上へ、↓ を押しながら離すとそっと置きます。持ったまま ↓ でしゃがむと足元で抱えます。
  押さずに触れると蹴り飛ばし、壁に当たると砕けます。持っている間はスピンジャンプできません。
- **甲羅**（SMW のノコノコの甲羅）：ギフトと同じく持つ・投げる・置くができます。蹴る/投げると滑り、壁に当たると跳ね返ります（ブロックを叩く）。
  滑っている甲羅は敵を倒し、横から当たるとダメージ。上から踏むと止まり（ルミナは跳ねる）、スピンジャンプで踏むと消えます。
  置いた・真上に投げた甲羅（気絶状態 status 9）は、空中にある間だけ敵を倒します。床の上では敵が向きを変えるだけ（SMW の 01A4BA と同じ）。
  持っている甲羅・ギフトが敵に触れると、敵も持っている物もやられて落ちていきます（SMW の `sub_1A685`。ルミナはダメージを受けない）。
- **ゴール**（SMW のゴールテープ `Spr07B_GoalTape`）：2 本の柱の間をテープが上下（124 フレームごと、速さ 12）。柱の間を通るとゴールで、テープに触れると切れて飛んでいく。
  ゴールした後はボタンが効かず、SMW と同じく右へゆっくり歩かされ（`PlayerState00_HandleEndOfLevel`：毎フレーム横の速さ 5）、止まると勝利ポーズを 64 フレーム。
  画面の敵と持っている物は星になって消える（SMW ではコイン）。「コースクリア！」のあと、ステージの最初からやり直し。
- **金のブロック**（ターンブロック）：空中でスピンジャンプ中に着地すると壊れ、ルミナが少し跳ね返ります（縦速度 -48。ジャンプボタンを押していると重力が弱いので約 2 倍高く跳ぶ）。段を重ねたブロックは跳ねながら順に壊せます。
  下から叩く（または滑る甲羅・ギフトが横から当たる）と、SMW のクルクルブロックのように跳ねてから回り始め、回っている間はすり抜けられます。叩いてから 256 フレーム（約 4.3 秒）で元に戻ります。
- **トゲムシ**：普通に踏む・横から触れるとダメージ（SMW と同じくノックバックは無く、一定時間無敵になって点滅）。
  スピンジャンプで上から踏むと倒さずに跳ね返ります（B を押していると高く跳びます）。投げたギフトで倒せます。
- **坂**（SMW の坂の形 `SlopeDataTables`）：ゆるい坂（2 タイルで 1 段）と 45° の坂。坂ごとの加速・最高速・摩擦の表を使い、
  45° の坂で何も押さないとゆっくり滑り落ちる（静止速度 -16）。速く登ると坂に沿った上向きの速度になる。
  坂で ↓ を押すとしゃがみ滑り（ポーズ 0x1C）になり、坂を下る向きに加速する。滑っている間は敵を倒す。
  丘の頂上と中身は「上からだけ乗れる足場」（SMW の map16 0x100〜0x110 相当）で、坂の真下の地面は SMW の坂補助タイル（0x1D8〜）と同じく上の坂として扱う。
- **水中**（`HandlePlayerPhysics_Swimming`）：体の中心と頭が水に入ると泳ぐ。B で水をかく（-32）、重力は 4 フレームに +2、
  上昇の上限は -24（↑ で -48、↓ で -8）、沈む速さは最大 0x40。水面では ↑+B で飛び出す（-86）。物を持っているとゆっくり浮かぶ。
- **ツタ**（`HandlePlayerPhysics_Climbing`）：体の中心と頭がツタにかかった状態で ↑/↓ を押すとつかまる。上下は 1px/フレーム、
  頭がツタから出ると止まる。横は中心がツタにある間だけ動け、外れると手を離す。B で飛び降りる（-80）。
- **天井の坂**（SMW の坂の形 18〜23 番：45° と、2 タイルで 1 段のゆるい坂）：頭の点が坂の固い部分に入ると押し戻され上昇が止まる（`RunPlayerBlockCode` の LABEL_62）。
  地上で頭が 7px 以内だけ入るなら頭打ちのみ、深いと前へ進めない。坂の真上のブロックは SMW の補助タイルと同じく下の坂として扱う。
- **チビルミナ**（パワーアップ $19）：SMW と同じく小さい状態で始まる。判定点・当たり判定はしゃがみと同じ、歩きは 2 コマ、物は +15 の高さで持つ、
  スピンジャンプでターンブロックを壊せない。**？ブロック**を叩くと光の玉（動きは SMW のキノコと同じ：62 フレームでブロックから出て 1px/フレームで転がる）。
  光の玉を取ると大きくなる（47 フレーム停止）。大きい時のダメージで縮み（47 フレーム停止の後 0x7F フレーム無敵）、小さい時のダメージ・穴に落ちるとミス
  （`PlayerState09_Death`：縦速度 -112、最初の 40 フレームは静止、4 フレームに 1 減るタイマー 0x30 が 0 でやり直し）。
- ブロックとの当たり判定は SMW の `RunPlayerBlockCode` と同じ 6 点（中心・左右の横 2 点・頭・足 2 点）方式です。
  立ちは 中心 y+0x12 / 横 y+0x1A・y+0x0F / 頭 y+0x08 / 足 y+0x20、しゃがみは 中心 y+0x18 / 横 y+0x1A・y+0x16 / 頭 y+0x10。

## オーバーワールド（地図）

ゲームを開くと、SMW のような地図から始まります（`js/overworld/`）。十字キーで道を歩き、点の上で B（または A）を押すとステージに入ります。

- 黄色の点 = まだ、青い点 = クリア、灰色 = 準備中（まだ作っていないステージ）。お城はクリアすると旗が青くなる。
- クリアすると地図に戻り、次の道が 1 マスずつ現れる。ミスすると地図に戻る（小さくなる）。ステージの途中で 🗺（M キー）を押すと地図へ戻れる（クリアにはならない）。
- お城（○-5）をクリアすると、次のワールドへのワープ（紫の星の輪）が開く。ボス部屋（○-5B）をクリアすると、お城のクリアになる。
- 進み具合（クリアしたステージ・いる場所・大きさ）はこの端末に自動で保存される。ヘルプ（?）の「セーブデータを消す」で最初から。
- `?level=1-3` のように URL に書くと、地図を通さず直接遊べる（今までどおり）。

### 隠しゴールと隠しコース（寄り道）

SMW の「もう 1 つの出口」と同じ仕組みです。

- **ひみつのゴール**：桃色と紫の柱のゲート。ふつうのゴールとは別の、見つけにくい場所にある。通ると地図に記録され（`1-3*` のように `*` 付き）、隠し道が開く。
- 地図では、ひみつのゴールがあるステージは**赤い点**。クリアしてもまだ見つけていなければ小さな赤い印、見つけると金色の輪がつく。
- 隠し道の先は**隠しコース**（桃色の星の点）。隠しコースをクリアすると、お城の前への近道が開く。隠しコースへの道は、ひみつのゴールか隠しコースのクリアでしか開かない（お城の側からは開かない）。
- 地図の「クリア」は出口の数（ひみつのゴールも 1 つと数える）。

### 地図の作り（あとからステージを足すには）

`js/overworld/maps.js` に、ワールド 1〜8 とエクストラ（ほしの道）の 9 枚の地図があります。1 文字が 1 マスで、

- 地形：`.` 地面 `,` 色ちがい `~` 水（テーマで空・マグマ・宇宙）`^` 山 `T` 木 `*` 飾り `B` 建物
- 道：`-` 横 `|` 縦 `+` 曲がり角。点（`1`〜`4`、お城 `C`、入口 `P`、次のワールドへ `N`、エクストラの門 `X`、エクストラの `a`〜`j`）どうしは道で自動でつながる。
- 道は、両はしの点のどちらかが「開いている」（はじめの家・ワールドの入口・クリアしたステージ）と通れる。

ワールド 1〜8（各 1〜4 とお城）とエクストラ 10 ステージ（E-1〜E-10）の点は、もう地図に置いてあります。
まだ無いステージは「準備中」になり、その先の道は開きません。新しいステージは `js/stages/index.js` の `STAGES` に同じ id（例 `4-1`、`E-3`）で足せば、地図からそのまま遊べるようになります
（ボス部屋は `hidden: true, credit: '4-5'`、隠しコースは `4-S`）。エクストラ（ほしの道）の門は、ワールド 8 のお城（8-5）をクリアすると開きます。
地図そのものを大きくしたい時は、行と列を増やすだけでよい（画面より大きい地図はルミナについてスクロールする）。

## 1-1 アキハバラ

ゲームを開くと最初に遊ぶステージです（`js/stages/akihabara.js`）。参考動画のステージ 1 の流れ
（スタート → 砲台の砲弾を足場に谷越え → 地上の敵 → 空中のブロック地帯 → 天井つきの地上 → 高い柱の区間 → ゴール）に沿って作り、
敵・仕掛け・見た目は電気街をテーマにしたオリジナルに置き換えています。

- **砲台と砲弾**（SMW のキラー砲台 `ShooterSpr01_BulletBillShooter` と `Spr01C_BulletBill`）：砲台は 192 フレーム（約 3.2 秒）ごとに、
  画面の中にあって（右端 16px は除く）ルミナが横に 17px 以上離れている時だけ撃つ。砲弾は撃った時にルミナのいた側へ 2px/フレームでまっすぐ飛び、
  地形はすり抜ける。上から踏める（踏むと落ちる）ので、谷では向こう岸の砲台から飛んでくる砲弾を足場にできる。砲台は積んで柱にできる（1 マスが 1 つの砲台）。
- **ガチャカプセル**：地面をころころ転がる。壁で向きを変える。上から踏める。
- **警備ロボ**：その場でときどき跳ねる。3 回踏むと倒れる。
- **ドローン**：左右に行き来しながらふわふわ上下する。踏むと落ちる。
- **電気スパーク**：ダクトの上などから一定の間かくで跳ね上がる。踏めない（スピンジャンプなら跳ね返れる）。
- **下向きのトゲ**：天井から下向き。頭をぶつけるとダメージ。大ジャンプだと刺さる高さに置いてある所がある。
- **メッセージブロック**：下から叩くと文が出る（その間ゲームは止まる。B/Y/A で閉じる）。
- **高架の線路**（上からだけ乗れる）・**コンクリート**・**ダクト**・**ネオン看板**（飾り）、テーマ「電気街」（夕暮れのビル街）。
- 始まる時に「1-1 アキハバラ」と出る。今までの操作確認用ステージは `index.html?level=test` で遊べます。

これらの敵・タイルはエディタでも使えます（「電気街」「仕掛け」「敵・アイテム」）。☰ から 1-1 を読み込んで改造することもできます。

## 1-4 そよかぜの丘 / 1-5 かげの城 / ボス

どちらもステージエディタで作ったステージです（`tools/build_stage_1_4.cjs`・`tools/build_stage_1_5.cjs`。共通部分は `tools/editor_driver.cjs`）。

- **1-4 そよかぜの丘**（草原）：丘が続く。金のブロックと甲羅、ツタで登る空の道（下は石の足場の谷）、池、砲台の丘、穴、大きな丘を越えてゴール。
- **1-5 かげの城**（お城）：マグマと木の橋、下向きトゲの低い廊下、ハシゴで越える鉄の塔、砲台の間、長いマグマ、番人の警備ロボ。ゴールの代わりに**ボス扉**がある。
- **ボス扉**：扉の前の地上で ↑ を押すと入る（SMW の扉と同じ条件）。行き先はステージごとに決められる（1-5 は「1-5B」＝ボス部屋。大きさは引き継ぐ）。
  行き先が空なら、入るとそのままクリア。
- **ボス「かげの王」**（オリジナル。`js/actors.js` の `Boss`）：歩いて近づき、かげの玉を投げる・大きく跳ぶを交互に行う。
  上から踏む（か、甲羅などを当てる）とダメージで、トゲの球になって部屋を転がる（この間は踏めない・触れるとダメージ）。弱るほど速くなり、3 回で倒れてコースクリア。
  ボス部屋でミスすると、ボス部屋の最初からやり直し。

- **2-2 みずの洞窟**（洞窟）：長い池と岩の棚、マグマ、ハシゴで越える岩の壁、下向きトゲのある池、砲台、長いマグマ、低い天井。

## ステージエディタ

`editor.html`（ゲーム画面右上の ✎）でステージを作れます。作ったステージはブラウザに自動保存され、「▶ テストプレイ」でそのまま遊べます（ゲームの ✎ でエディタに戻る）。

- パレットからタイル・敵・アイテムを選び、ステージに置きます。✏️ ペン（なぞって置く）/ ▭ 四角（範囲を埋める）/ 💧 スポイト（置いてある物を選ぶ）/ ✋ 手（スクロール）。
- スクロール：下のスライダー、マウスホイール、右ドラッグ、2 本指ドラッグ、← →。
- ↶ ↷ で元に戻す・やり直す（Ctrl+Z / Ctrl+Y）。# でマス目の表示（G）。
- 「名前」に入れた文字は、ステージの始まりに表示されます（空なら表示なし）。
- 「スクロール」で強制スクロール（遅い・速い）にできます。ゴールは最後の画面（スクロールが止まる所）に置きます。
- 「暗やみ」にすると、ルミナと光る物のまわりだけが見えるステージになります（たいまつを置くと明かりになる）。
- テーマ（草原・洞窟・遺跡・お城・電気街・空・ネオン・火山・やみ・宇宙・家の中）で背景と地面・坂の色が変わります。幅は 16〜1024 マス、高さは 27 マス。
- 「その他」でスタート位置とゴールを置けます（どちらも 1 つ。ゴールを置かないとクリアの無いステージになります）。
- ☰ から、新しいステージ・標準のテストステージ・ファイルへの書き出し／読み込み（.json）。
- ？ブロックは「光の玉入り」と「からっぽ」の 2 種類。オレンジの縦線は画面 1 枚分（256px）の目安です。

### テーマ用のオブジェクト

どのテーマでも使えます。仕掛けとして、次の 3 つも追加しました（いずれも SMW の処理を移植）。

- **トゲ**：固いブロック。乗る・横から触れる・頭をぶつけるとダメージ（SMW のムンチャー／お城のトゲ。`RunPlayerBlockCode_CheckIfPlayerTouchingHurtBlock`）。

## SMW から移植した挙動

`js/player.js` は SMW の `PlayerState00`（$00CC68）以降を、8bit/16bit 演算の
桁あふれも含めて再現しています。テーブルは `js/smw_tables.js`。

- 加速・減速・切り返し（ブレーキ加速）・最高速（歩き 20 / ダッシュ 36 / P スピード 48）
- 最高速付近での速度の振動（加速 0x180 と減速 0x100 が交互にかかる）
- P メーター（ダッシュ 35 以上で +2/フレーム、満タン 0x70）
- 速度で変わるジャンプ初速、B 押しっぱなし時の重力 3 / 離し時 6、落下速度上限
- スピンジャンプ、しゃがみ（しゃがみジャンプ含む）、上を見る
- 歩き/走りアニメーションの速度テーブル、ポーズ選択
- カメラの横スクロール（$00F6DB、進行方向へ 1px 先行）と画面端の押し戻し
- カメラの縦スクロール（$00F7F4）：画面の上から 100〜124px に保つ。下へは 5px/フレーム、上へは 3px/フレームで、空中では着地するまで待つ（ツタ・泳ぎ中は待たない）
- 60.0988 Hz 固定フレーム
- 強制スクロール（`Spr0F3_RegularAutoScroll` → `Layer1SpecialScrolling0C_RegularAutoScroll`）：速さ（1/256px）を毎フレーム 1 ずつ上げて
  0x80（遅い）/ 0x100（速い）で止め、`UpdateLayerPositionWithScrollSprite` と同じ端数の足し方で画面を動かす。最後の画面で止まる
- 画面端（`HandlePlayerLevelColl_00E98C`〜`00EA0D`）：ブロックに当たっていなければ画面の左右の端（左 8px・右 232px）で押し戻す。
  強制スクロール中は端でルミナの横の速さをスクロールの速さにそろえる (`00E9C8`)。画面の左の外 16px 以内に出たらミス（壁とはさまれた時）、
  ブロックに上下からはさまれて埋まってもミス (`00E9FB`)。ふつうのステージでの動きは今までと同じ
- 音符ブロック（Map16 0x115）：上に乗ると `CheckIfBlockWasHit(…, 3)` → バウンドスプライト（`BounceSpr01_TurnBlock`、向き 3）。
  初速 0x40・加速 -0x10 で 8 フレーム沈んで戻り、その間ルミナはブロックの上に固定（ypos = ブロック - 32、yspeed = 0、
  `misc_player_on_solid_sprite` で着地扱い。`00EE1D` の「スプライトの上」の分岐も移植）。タイマーが 0 になると yspeed = -96、ypos -= 2。
  跳ねている間は横から押し出さない（`blocks_note_block_bounce_flag`）。下から叩くと向き 0（初速 -0x40）で上に跳ねるだけ。
  処理の順番も SMW と同じ（ルミナ → スプライト → バウンドスプライト）

### ルミナの挙動で SMW と違うところ（意図的なもの・未実装）

- パワーアップは光の玉（SMW のキノコ相当）だけ（マント・ファイア・スター・アイテムストックは無し）。残機・タイマー・ミス後のメッセージは無く、ミスすると即やり直し。
- ゴールのボーナス（星の数・ボーナスゲーム）、ゴール時に持っている物がアイテムに変わる処理、クリア後の画面を丸く閉じる演出は無い。
- 縮む・大きくなる途中の「中くらい」の絵 (0x3D) は、大きい立ちポーズを縦に縮めたもの。
- しゃがんで物を持っているとき、物の横位置を SMW より 4px 前に出している（ルミナの顔が隠れないための見た目の調整。高さは SMW と同じ +15）。
- ギフトボックスは「Y を離すと投げる、↓+離すで置く」（SMW の甲羅の規則）。SMW のスローブロックは左右を押していないと置く。
- 急な坂（45° より急な坂・壁走り）、水の坂、ネット（金網）、マント・ヨッシー・L/R スクロールは未実装。
- 音符ブロックは「乗る・下から叩く」で跳ねる種類（Map16 0x115）だけ。横からも跳ねる種類 (0x116)・中身入りは無い。下から叩いた時に上に乗っている敵を倒す処理 (`InitializeBlockPunchAttack`) も無い。

テスト: `for t in physics world terrain power goal akihabara stage1_2 stage1_3 boss world2 world3 overworld secret world4 world5 world6 world7 world8 extra final; do node tests/$t.test.mjs; done`
